# AUDIT — platform (agent audit-platform)

## SYSTEM MAP
Export: app/api/export/[resource]/route.ts → requireUserContext → allowlisted EXPORTERS (28 resources) → per-resource userCan(exporter.permission) → load(params,range) → PDF renderTableReportPdf. Loaders use RLS user client or delegate to feature actions (re-check perms).
Search: MV public.search_index (7 entities) + search_global() RPC (security INVOKER, role→entity_type allowlist). Refresh: statement triggers → search_index_mark_dirty() (plain, NOT definer) → singleton search_index_state + pg_notify → cron search-index-refresh 1min → refresh_search_index_if_dirty() (definer service_role).
Files: files registry (RLS select true, insert self+role, delete uploader/admin) + file_attachments (9 FKs, exactly-one check; select true) + private bucket files (select/delete gated on registry-row existence, insert path-shape). Actions: upload (files:write+per-target, 10MB, MIME allowlist), sign (1h TTL no perm), detach (no perm), list (no perm). find_orphan_files RPC + nightly files-sweep-orphans.
Notifications: notifications (recipient-scoped RLS, realtime), inserted by chat triggers (honor settings+mute) + HR/fleet crons (service role, type document_expiring). Push: push_subscriptions + notifications-dispatch (idempotency message_id, chat only) + lib/push.ts (410/404 cleanup).
Admin-users: gated users:read/invite/assign_role; owner-escalation blocked by canAssignRole; last-owner by deferrable trigger; roles re-read per request (no stale). bootstrapOwnerIfNeeded: first user self-elevates.
Backups: GH Action daily pg_dump -Fc → private bucket backups-daily (service-role only), 30-day prune, sha256. UI gated audit:read, signed URL 5min, filename regex-allowlist. Restore: manual script.

## DESIGN TENSIONS
1. Registry-gated storage vs write-first upload: storage INSERT can't check registry (row doesn't exist yet) → bucket accepts any authenticated write; sweep only trusts registry. Gap between "bytes first" and "row later" is where orphan-definition + untracked-blob bugs live. Service-role-only upload collapses both.
2. RBAC matrix in TS mirrored by hand in SQL: search_global role map, RLS role arrays, cron fan-out lists all hand-copied from permissions.ts. Two drifted (search map; files:read). No generator or test asserts the mirror.
3. document_expiring reuses chat notification pipe but rejects its preference/preview/href contract — every new non-chat emitter re-hits same 3 gaps.

## EXPECTATION GAPS
- "Backups" = DB only. pg_dump covers Postgres; files/avatars/invoice-PDF buckets NOT backed up — restored files rows point at lost blobs. Restore drill checks only public-table row counts; auth-schema restore punted.
- Exporter registry pattern held up (allowlist + per-resource perm; no injection; classic generic-export authz hole NOT found) — failures are truncation/aggregation not access.
- "TTL cleanup deleting undelivered notifications": REFUTED — ttl-cleanup never touches notifications; actual issue is opposite (no retention).
- "Admin escalate to owner": REFUTED — blocked in canAssignRole + UI; last-owner protected by deferrable trigger; role changes per-request fresh.
