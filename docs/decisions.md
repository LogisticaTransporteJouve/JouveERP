# Decisiones

Registro fechado de decisiones de diseño. Cada entrada: qué se decidió, por
qué, y qué se descartó.

Ver la carpeta [`decisions/`](decisions/): un archivo por decisión,
`YYYY-MM-DD-<tema>.md`, con el título `YYYY-MM-DD — <tema>` como H1. El
nombre empieza por la fecha, así que el orden de la carpeta es el cronológico
(la más nueva al final).

## Cómo agregar

Para agregar algo, creá un archivo nuevo en esta carpeta
(`docs/decisions/YYYY-MM-DD-<tema>.md`, H1 `YYYY-MM-DD — <tema>`); no edites
archivos de otros PRs salvo para marcar un ítem.

Este índice no lista los archivos a propósito: si cada PR sumara una línea
acá, dos PRs en paralelo chocarían en el mismo lugar, que es justo lo que
esta carpeta evita.
