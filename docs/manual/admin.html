Usuarios y roles

Alta, baja y asignación de roles de los usuarios que pueden ingresar al ERP. El primer usuario que entra al sistema se vuelve owner automáticamente ("bootstrap"); a partir de ese momento, los nuevos vienen por invitación.

Ubicación: sidebar > Admin > Usuarios.

Listar usuarios

Tabla con nombre, email, avatar, roles actuales y última actividad.

Invitar usuario

  1. Click en Invitar usuario.
  2. Email (requerido) + al menos un rol.
  3. Al confirmar, el usuario recibe un mail con link de alta.

Asignar / revocar roles

  1. En la fila del usuario, abrí el dropdown de roles.
  2. Tildá / destildá. Owner puede asignar cualquier rol incluso owner; admin puede todos menos owner.
  3. El sistema impide quedarse sin owners: no podés revocarle el rol al último owner.

Padrón AFIP

Consulta directa al padrón AFIP por CUIT. Devuelve razón social, condición frente al IVA y domicilio fiscal. Se usa desde el alta de cliente / proveedor (botón Verificar AFIP), pero también está disponible como herramienta standalone.

Ubicación: sidebar > Admin > Padrón AFIP.

  1. Ingresá un CUIT de 11 dígitos.
  2. Click en Buscar. El resultado se cachea 24 horas.
  3. Hay un rate limit de 60 consultas por hora por usuario, para no quemar el cupo AFIP.

Permiso: padron:lookup.

  2. Sincronizar: botón Sincronizar AFIP trae el listado de POS habilitados y actualiza la tabla local.
  3. Configurar POS: abrir un POS y asignar canal, alias y el toggle habilitado. Para habilitarlo es obligatorio asignarle canal.

Usuario de ARCA para Mis Comprobantes

En la misma pantalla, Usuario de ARCA para Mis Comprobantes guarda el CUIT y la clave fiscal con la que JouveERP baja todos los días los comprobantes recibidos de ARCA. Usá un usuario al que DZ & Sons le delegó solo el servicio Mis Comprobantes.

  1. Click en Configurar (o Cambiar).
  2. Cargá el CUIT del usuario y su clave fiscal. Para cambiar solo el CUIT, dejá la clave vacía.
  3. Guardar. La clave se guarda cifrada y no se vuelve a mostrar.
Si ARCA rechaza la clave, o el ingreso falla dos veces seguidas mientras ARCA evalúa la clave (bloqueo, un error de ARCA al validarla), JouveERP deja de entrar para no bloquear el usuario en ARCA. El panel dice por qué. Si ARCA está caído o pide captcha antes de la clave, no cuenta: vuelve a probar en la próxima corrida. Si ARCA ya aceptó la clave y falla después (el portal o Mis Comprobantes), tampoco cuenta y reinicia la cuenta de fallas. Para que vuelva a entrar, cargá la clave otra vez (la misma, si no cambió) y guardá.

El estado dice si está funcionando y cuándo fue el último acceso. Si ARCA rechaza la clave, dice ARCA rechazó la clave: actualizala y no se vuelve a intentar hasta que guardes una clave nueva (o un CUIT distinto). Lo editan owner y admin.

Permiso: afip:admin (owner / admin).

Preview de PDF de comprobantes

Visualizador para diseñar / verificar cómo sale el PDF de cada punto de venta. Útil después de cambiar el logo, el footer o el formato del comprobante.

Ubicación: sidebar > Admin > Preview PDF.

  1. Elegí POS + un comprobante de muestra (puede ser real o dummy).
  2. Se renderiza el PDF tal cual le va a llegar al cliente por email.

Importador de planillas

Carga datos de arranque desde una planilla .xlsx o .csv: maestros (clientes, proveedores, empleados, vehículos), históricos de referencia y los importes de arranque (tarifas, préstamos, cheques en cartera, saldos de clientes y extractos bancarios).

Ubicación: sidebar > Admin > Importador.

  1. Elegí el tipo (y la cuenta o el canal, si el tipo lo pide).
  2. Subí la planilla. El sistema busca la fila de títulos entre las primeras 15 y propone qué columna es cada dato; podés cambiarlo.
  3. Revisá la vista previa: cada fila queda Lista, Ya existe o Con error, con sus avisos.
  4. Click Importar: entran todas las filas listas en una sola transacción. Las filas con error no entran y se cuentan.

Reglas comunes

  • Archivo: hasta 4 MB, 5000 filas y 60 columnas. Si es más grande, dividilo.
  • Títulos: se comparan sin mayúsculas ni acentos ("Razón social" = "razon social"). Cada columna lista sus nombres aceptados; también vale un título que empiece con uno de ellos ("Litros (lts)").
  • Fechas: 31/10/2026, 31-10-26 o 2026-10-31.
  • Importes: notación argentina (1.234,56) o simple (1234.56).
  • Sí / No: "Sí", "S", "X" o "1"; "No", "N" o "0" (vacío = No).
  • Sin duplicados: cada tipo compara por su clave natural (CUIT, CUIL, patente…). Reimportar el mismo archivo no duplica nada; un registro que ya existe no se actualiza.
  • Deshacer: cada corrida queda en el historial y se deshace mientras nadie editó ni usa sus filas.
  • Las filas totalmente vacías (o de subtotal) se saltean.

Backups

Descarga de los backups diarios de la base. Se generan por un cron externo y se guardan en el bucket backups-daily.

Ubicación: sidebar > Admin > Backups.

  1. El listado muestra un archivo por día con formato backup-YYYY-MM-DD.dump, tamaño y hash SHA256.
  2. Click Descargar > el sistema genera un signed URL de 5 minutos.
  3. Verificá el hash SHA256 contra el del archivo para confirmar integridad.
Cuidado. El backup contiene datos sensibles. No lo subas a servicios públicos ni lo compartas por canales no autorizados.

Permiso: audit:read (owner / admin).
